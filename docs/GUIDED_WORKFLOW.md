# Guided local editing

## Setup and review

`python -m ai_event_editor.desktop` opens three tabs: Footage & music, Review moments, and Create edit. The legacy renderer remains available from the setup tab and `--legacy`.

Choose footage files or a recursive folder, optional music, an excerpt in seconds, output length (30–300 seconds), style and pacing. A blank music end means start plus edit length. Creation probes the audio stream and rejects short or out-of-bounds excerpts. **Listen to excerpt** uses FFplay without changing or copying your music.

Default preparation probes media, creates four-second non-overlapping windows and temporary PPM thumbnails, and labels them `performance` as a manual-review default. This default is not a claim about their content. Scores display **Unranked**. Change categories as needed. Optional CLIP uses only cached model weights; missing packages or weights produce an error, not a hidden download. AI quality scores are exposure/detail heuristics, not confidence that a shot matters to the story.

Unreadable files are reported individually; successful files remain usable. Thumbnail failure leaves a reviewable moment in place. Re-preparing unchanged media preserves category and review choices for matching moment IDs. Saved reviews store all decisions and source ranges; temporary thumbnails may need regeneration after reopening or restarting.

Review supports multi-selection for **Keep**, **Reject**, **Must include**, and category changes. Selecting a row shows its thumbnail; **Preview moment** plays its source range. Kept moments are eligible and may not all appear. Must include pins guarantee at least one useful excerpt from each pinned moment when they fit. They do not pin a full performance, force the whole source range, or lock the final Premiere timeline. Overlapping pins and pins that cannot fit require adjustment or a longer edit.

## Planning

The planner validates and removes overlapping non-pinned source windows, then redistributes category weights within actual available footage. Missing drone, crowd, stalls or other categories are coverage warnings. A category cannot reserve more time than its usable footage. If the total footage is too short, creation reports the shortage instead of duplicating frames. Long source ranges can supply multiple non-overlapping cuts.

Calm, Balanced and Energetic change cut length independently of effects. Music is decoded locally through FFmpeg into a small mono PCM buffer (at most five minutes). A quarter-second RMS envelope adjusts cut targets around louder passages; transient peaks supply approximate cut anchors. This is a deterministic heuristic, not a trained beat/structure detector or a claim that louder always means a musically significant drop. Review and revise the result.

The saved plan includes authoritative source seconds, stable review IDs (`shot_id`), pin metadata, coverage warnings, pacing and the music path/excerpt start. Render-file loading uses embedded music when an explicit music path is not supplied. Original clips/music are never overwritten by rendering. Review and edit files are local, readable JSON generated by the app; users do not have to author it.

## Premiere handoff

This milestone uses a local file handoff: **Save edit for Premiere**, then **Open reviewed edit** in the UXP panel. There is no server, cloud upload, network permission, or second AI engine in the panel. Setup and review run in the desktop app; the panel consumes the resulting plan. Its older duration/instruction scaffold does not rewrite imported plans; the instruction field is reserved and not interpreted.

Native assembly is experimental and requires Premiere 26.3+:

1. Validate the plan, reject unsupported speed/title effects, and obtain the active project.
2. Create a new bin and import local sources. Create named, hard-bounded video-only subclips plus an optional audio-only music subclip. Source in/out marks stay unchanged.
3. Create a new, empty sequence with a unique name. Set its frame rate and place subclips at planned times using undoable transactions. Existing sequences are not touched. Default Premiere sequence geometry is retained.
4. Check the resulting duration and open the new sequence for review. No automatic project save or cleanup deletion occurs. A failed operation can leave new imported items and a partial sequence for inspection.

The adapter is checked against Adobe's documented API signatures and tested with an explicit mock host. Installed Premiere behavior, source timecode offsets, mixed-source frame alignment, codec support, framing, transactions and sound must still be verified on a Windows/Premiere machine before release.

## Later stages

Separate effect frequency controls (None/Subtle/Energetic), reviewed interview/speech quotes, B-roll over speech, music ducking, actual speed rendering, native title/effect support and Windows packaging are unfinished. They are not implied by the style names or by passing unit tests.
